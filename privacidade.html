Política de Privacidade – PA Whisper

Atualizada em 27/10/2026.

  1. Quem usa. O PA Whisper é uma ferramenta pessoal, usada apenas pelo dono da conta Google que a autorizou.
  2. Que dados acessa. Só os arquivos da pasta do Google Drive escolhida pelo dono: lê os áudios da subpasta de entrada e grava a transcrição na subpasta de saída.
  3. Para que usa. Exclusivamente para transcrever esses áudios. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.
  4. Onde fica. O processamento acontece em um servidor particular do dono. A credencial de acesso fica guardada só nesse servidor.
  5. Como revogar. O dono pode remover o acesso a qualquer momento em myaccount.google.com/permissions.
  6. Dados do Google. O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
